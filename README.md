# AI Hill Climbing Search Algorithm

A simple implementation of the Hill Climbing Search Algorithm using Python.

## About

Hill Climbing is a local search algorithm used in Artificial Intelligence.

The algorithm starts from an initial state and continuously moves toward a
better neighboring state until no better solution can be found.

## Features

- Hill Climbing Search Algorithm
- Objective function optimization
- Simple Python implementation
- Beginner-friendly AI project

## Technologies

- Python 3

## How to Run

Make sure Python 3 is installed on your computer.

Then run:

```bash
python hill_climbing.py
